# LBA1 rendering research and current result

The viewer uses native Godot meshes, a spatial shader, and a custom `light()` function on Godot 4.8 beta1's Compatibility renderer. It does not upscale a low-resolution framebuffer. The capture test rendered a true 3840×2160 image through an offscreen `SubViewport`.

## Lighting and palette

`lba1-classic/LIB386/LIB_3D/P_OB_ISO.ASM`, `ComputeAnimNormal` computes a light response for each source normal using its stored divisor. `polygouraud` adds that response to the polygon's base palette index at each vertex. `lba1-classic/LIB386/LIB_SVGA/S_FILLV.ASM`, `SVGAPolyGouraud` interpolates 8.8 fixed-point indices across scanlines and emits their high byte. The viewer carries source normals and divisors in mesh custom data, computes a palette-index offset in `vertex()`, interpolates it into `fragment()`, and samples `RESS.HQR` entry 0. Source-style shading does not clamp the offset. Soft dither clamps its preview lighting within the source palette's 16-colour ramps: BODY #15, #17, #30, and #35 otherwise cross high-contrast ramp boundaries, making dark speckles move across light surfaces as the pose changes.

`lba1-classic/LIB386/LIB_SVGA/S_PAL.ASM`, `Palette` shifts source RGB bytes right by two for the six-bit VGA DAC. The palette texture applies that conversion. Godot ambient energy is zero. One white light and `light()` pass the palette colour without modern specular highlights, compensating for Godot's `LIGHT_COLOR` PI factor. The fixed source-light vector approximates the game's default `SetLightVector(896, 950, 0)`; original integer trig, group rotations, and raster interpolation remain unmatched.

## Dither and the supplied LBA1 screenshot

`SVGAPolyDith` is a dedicated LBA1 scanline routine with fractional carry and low-byte rotation. Body material tags matter: Twinsen BODY entry 0 contains 204 Gouraud faces, 18 flat faces, and only 2 dither faces, neither on his robe. A survey of entries 0–39 found many other characters with 80–200 type-10 dither faces. BODY entry 9 has 86; its source-face capture shows dither across a light coat. This is consistent with the user's LBA1 screenshot showing a dithered cast, while explaining why source-face mode barely affects Twinsen's robe.

The viewer offers **Soft dither** by default, **Modern smooth**, and **Dither off**. Dither off shows the palette bands under the same source light values as Soft dither. Soft dither extends its anchored pattern to Gouraud faces; it must not be mistaken for an original material assignment. Modern smooth computes lighting per fragment from interpolated source normals, then blends adjacent palette colours. It removes palette bands and dither while retaining the model geometry and source palette.

Soft dither uses a model-anchored threshold and fades to smooth shading when its pattern becomes too fine to resolve. It interpolates the original LBA1 vertex light value, so its average palette shade follows the source bands without an added ambient lift. It clamps the interpolated shade within each 16-colour palette ramp to avoid unrelated colour speckles. The original row phase, polygon-edge rounding, and carry rotation are **not byte-exact** to `SVGAPolyDith`.

The LBA1 screen-space `P_OB_ISO.ASM` `testpoly` rejects backfaces. BODY #17 has several coincident reverse-wound polygons, including ear pairs 145/146 and 147/148. The old `cull_disabled` shader rendered both sides and produced visible depth fighting. The native mesh now reverses each triangle's source order to match Godot's front-face convention and uses `cull_back`. This removed the visible ear conflict in the Grobo capture. Lines remain thin four-sided cylinders; spheres are low-poly Godot spheres. Their original screen-space size and raster behaviour remain open.

LBA1 actor shadows are a separate graphic bank, not ordinary polygon dither. `SOURCES/COMMON.H` identifies `RESS.HQR` entry 4 as `RESS_SHADOW_GPH`; `SOURCES/OBJECT.C` selects sprite 2 for actors. The decoded sprite is 27×17 with 182 covered pixels, all palette index 16, arranged in a checker-pattern oval. The viewer renders that exact coverage and colour as a nearest-filtered native ground plane on the replaceable display block. The plane's 3D placement and scale are an approximation of the original screen-space `AffGraph` placement.

The original `S_FILLV.ASM` `SVGAPolyTrame` skips alternating destination pixels. `SVGAPolyTrans` combines the source palette index's high nibble with the destination's low nibble. The viewer now puts source type-5 and type-6 polygons in a separate transparent pass: type 6 uses checkerboard coverage, while type 5 uses half-alpha RGB as an approximation of palette-nibble compositing. A scan of all 132 LBA1 BODY slots found 15 type-5 faces across four bodies and 14 type-6 faces across five bodies. BODY #130's six cyan cab faces now reveal the model interior. This was verified with a native GPU capture, but a matched original-game frame is still needed for exact colour comparison.

`SVGAPolyCopper` (source type 2) walks up and down the 16-colour palette ramp, one step per source scanline. `SVGAPolyBopper` (type 3) uses the same ramp but holds each colour for two scanlines. The viewer now renders all 43 Copper faces and all five Bopper faces in the LBA1 archive at a 480-line reference scale. Three Copper faces are BODY #54's cabin windows; all five Bopper faces belong to ferry BODY #51, four of them on its upper cabin. The earlier conclusion that the ferry was only scene art was wrong. Both GLBs carry model-attached ramp textures as portable approximations. The live shader's phase is screen-anchored, so it does not precisely reproduce the game's per-polygon scanline start. The small boat's red-and-white roof fixture is already in BODY #54; neither that BODY nor its source scene provides a separate side-searchlight actor.

The other sparse LBA1 palette modes are `SVGAPolyTele` (source type 1, six faces on six bodies) and `SVGAPolyMarbre` (type 4, eight faces on four bodies). Tele varies four palette entries from the face's base colour with a screen-pixel pattern; the viewer uses a stable hash in place of the original rasterizer's running seed. Marble interpolates the low and high bytes of the source colour word across the face, taking the signed shortest route through the 256-colour palette. BODY #16's 240-to-0 headlights therefore cross the palette wrap into greys, not through all 240 unrelated colours. GLB and Blender use model-attached textures for portable approximations of both modes. The dither shader path was not changed for these effects.

Soft dither now randomly rotates its 8×8 local threshold domain from tile to tile, with a different hash seed per tile. This breaks repeated orientation while preserving the model anchor and footprint fade. Hexagonal tiles were not added; the rotational change is cheaper and was checked on the boat, digger, and several other copper-face bodies. LBA2 lighting remains untested. The LBA1 shader and animated model were rendered in the Godot 4.8 beta1 WebGL2 export in a browser.

Next fidelity work is a matched original-game capture, integer light-vector reconstruction, and representative palette-index comparisons along Gouraud and dither scanlines at multiple output resolutions.
